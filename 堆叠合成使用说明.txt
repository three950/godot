===============================================
堆叠卡牌自动合成系统
===============================================

## 功能说明
- 当卡片堆叠时（数量 > 1），自动检测是否可以合成
- 仅应用于资源卡（ResourceCard）和装备卡（EquipmentCard）
- 合成检测有 0.3 秒延迟，避免频繁检测

## 工作原理

1. 【自动初始化】
   - 资源卡和装备卡在 _ready() 时自动添加 StackCraftDetector 组件
   - 检测器会监听父卡片的 card_stacked_on 信号

2. 【堆叠触发】
   - 当玩家拖动卡片堆叠到另一张卡片上时
   - 底牌的 card_stacked_on 信号触发
   - StackCraftDetector 收到信号，开始倒计时

3. 【延迟检测】
   - 等待 0.3 秒后执行检测（避免连续堆叠时频繁检测）
   - 收集底牌 + 所有堆叠卡片

4. 【配方匹配】
   - 调用 CraftManager.check_craft() 检查配方
   - 使用字典统计材料数量 + 严格匹配算法
   - 必须材料种类、数量、总数完全匹配

5. 【执行合成】
   - 如果匹配成功，调用 CraftManager.execute_craft()
   - 删除所有材料卡片
   - 在底牌位置生成新卡片

## 文件结构

script_folder/craft_manager.gd
  - 全局单例，负责配方管理和合成执行
  - 自动从 CSV 加载配方

script_folder/stack_craft_detector.gd
  - 堆叠检测组件脚本
  - 附加到资源卡和装备卡上

assets/resources/resource_card.gd
  - 资源卡脚本
  - 自动添加检测器
  - 实现 get_card_name() 和 init_from_data()

assets/equipment/equipment_card.gd
  - 装备卡脚本
  - 自动添加检测器
  - 实现 get_card_name() 和 init_from_data()

## 配方示例（从CSV自动加载）

【资源类】
- 烤鱼 = 鱼 + 火
- 烤肉 = 肉 + 火
- 熟蛋 = 蛋 + 水 + 火 + 便携锅
- 鱼汤 = 鱼 + 水 + 火 + 便携锅

【装备类】
- 探窟稿 = 化石树的树枝 + 石块
- 骨弓 = 骨头×2 + 化石树的树枝 + 石头
- 石斧 = 化石树的树枝 + 石板

## 使用方式

### 正常使用（自动）
1. 运行游戏
2. 拖动卡片堆叠到一起
3. 系统自动检测并合成（如果配方匹配）

### 添加新配方
在 CSV 文件的"合成配方"列添加：
- 格式: "材料1*材料2*材料3"
- 支持数量: "材料1*材料2数量"
- 例如: "鱼*火" 或 "稿子*太阳石4"

### 调试信息
游戏运行时控制台会显示：
- [合成检测] 检测到 X 张卡片堆叠
- [合成检测] 可以合成: XXX
- [合成成功] 已生成新卡片于位置: ...

## 注意事项

1. 卡片必须实现 get_card_name() 方法
2. 卡片名称必须与 CSV 中的"名称"完全一致
3. 合成需要精确匹配，不能多余或缺少材料
4. 只在堆叠时触发，不会自动检测已有的堆叠

## 自定义调整

### 修改检测延迟
在 stack_craft_detector.gd 中修改：
```gdscript
var check_delay: float = 0.3  # 改为你想要的秒数
```

### 禁用某张卡的自动合成
在卡片的 _ready() 中注释掉：
```gdscript
# add_stack_craft_detector()
```

### 手动触发检测
```gdscript
var detector = card.get_node("StackCraftDetector")
if detector:
    detector.trigger_check()
```
